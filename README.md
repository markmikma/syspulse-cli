# SysPulse CLI 📊

**SysPulse CLI** is a lightweight, command-line system monitoring utility built in Python. Designed for Linux and Windows Subsystem for Linux (WSL) environments, it provides efficient tracking and logging of system resources and core performance metrics.

## Key Features
* **Resource Monitoring:** Real-time tracking of CPU, memory, and disk usage metrics.
* **Command-Line Interface:** Fast, lightweight, and scriptable CLI interaction.
* **WSL & Linux Compatible:** Optimized and tested for Linux-based systems and Windows Subsystem for Linux (WSL).
* **Structured Logging:** Reliable performance logging for infrastructure diagnostics and troubleshooting.

## Tech Stack
* **Language:** Python
* **Environment:** WSL (Windows Subsystem for Linux), Ubuntu/Debian
* **Version Control:** Git
